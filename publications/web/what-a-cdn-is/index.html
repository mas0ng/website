What a CDN is

What a content delivery network is, how it speeds up websites, and why it is not the same thing as the site itself.

A CDN, or content delivery network, is a set of servers that keep copies of a website's files close to the people requesting them. The point is speed and resilience, not a different website.

What problem it solves

The public internet is long. If every image, stylesheet, and script has to travel from one origin machine to every visitor, distant users wait, and a busy moment can overload that origin.

A CDN puts copies of those files at many points of presence. When you ask for a popular file, you are often served a nearby copy rather than the original every time.

That nearby copy is a cache. The same caveats as any browser cache apply: a change at the origin can take a short time to appear everywhere.

Origin and edge

Two words matter:

  • Origin is where the site actually lives: the source of the current files and the place that answers requests the CDN cannot.
  • Edge is a CDN location that may already have a copy, or will fetch one and keep it for a while.

A cache hit means the edge already had the file. A cache miss means it had to ask the origin, then it can store the answer for the next person.

Not every request is cacheable. A signed-in page, a search result, or a one-off form post usually has to go back to the origin. Public images, fonts, and scripts are the easy wins.

A CDN is not the website

Using a CDN does not mean a third party wrote the page. It means a delivery network is helping to ship files.

The site operator still decides what to publish. The CDN still sees ordinary request information needed to deliver those files: the address you connect from, the file asked for, the time, and similar connection details. That is how any internet delivery service works.

HTTPS can encrypt the path to the CDN. It does not hide the request from the network that is answering it.

What a CDN does not do

  • It does not make a site trustworthy.
  • It does not replace backups, or mean the origin can disappear forever.
  • It does not encrypt your data from the site operator.
  • It does not, by itself, stop tracking. A tracking file can be cached and delivered quickly too.

When something is wrong, a CDN can also serve an old file, a generic error, or a challenge page. That failure can look like “the website is down” even when the origin is fine, or the reverse.
