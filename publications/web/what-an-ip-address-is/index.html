What an IP address is

What an IP address is, what a website can tell from one, and why an address can be personal data without being a name.

An IP address is a number that identifies a device, or a point on a network, so that internet traffic can be delivered. Every ordinary website visit involves one.

The short version

When your browser asks for a page, the request has to come from somewhere and go somewhere. Those somewheres are IP addresses.

Your device has one that the public internet can see, or it shares one through a router. The site you visit has one, or several, that DNS pointed the name at. Packets travel between those addresses.

An IP address is not a passport. It is also not meaningless. Combined with time, the page requested, and other request information, it can often identify a household, a business, a school, or a person well enough to count as personal data.

Public and private addresses

Home and office networks usually use private addresses inside the building, such as the familiar 192.168.x.x range. Those are not unique on the public internet. The router then uses a public address for traffic that leaves the network.

What a website typically sees is the public address, which may belong to:

  • a home broadband connection
  • a mobile network
  • an office
  • a VPN or proxy
  • a café, hotel, or other shared network

Several people can appear to share one public address. One person can appear to change address as they move between networks.

IPv4 and IPv6

IPv4 addresses are the older four-part numbers, such as 203.0.113.10. There are not enough of them for every device, which is why sharing through routers is so common.

IPv6 addresses are longer. They exist because the internet ran short of IPv4 space. A connection may use one, the other, or both.

You do not need to read the number. You do need to know that “the IP address” is not one permanent tattoo on a person.

What a website can usually tell

From the address alone, a site can often infer a rough location, such as a country or city, and which network provider is being used. That is a guess from public routing data, not a precise map pin.

The address also arrives with other ordinary request information: the page asked for, the time, and the browser's user agent. Hosting and security services see this because they need it to deliver and protect the site.

An IP address can be used to:

  • send the response back to the right place
  • reduce abuse, spam, and automated attacks
  • diagnose faults
  • estimate country or network for security or localisation

It is a poor way to recognise a returning reader on its own. It is a common way to notice a burst of hostile traffic.

What it does not prove

An IP address does not prove who typed the request. It does not prove which person in a household was using the connection. It does not prove guilt by itself, and it does not survive every privacy tool: a VPN or shared network changes what the destination sees.

HTTPS can encrypt the content of the visit in transit. It does not hide the fact that two addresses are talking.
