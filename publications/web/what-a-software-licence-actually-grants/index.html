What a software licence actually grants

How software licences work, what open-source permission really means, and why a public file is not automatically free to reuse.

This is an explainer, not legal advice and not a licence. The summaries that apply to mas0ng.com releases are in Software Licensing. If a project ships its own LICENSE file or notice, that text controls. If this article and that text disagree, the licence text wins.

The default is no extra permission

Copyright exists automatically in original software, writing, images, and similar work. You do not have to register it. Public availability does not, by itself, authorise copying, modification, republication, redistribution, or commercial reuse.

If a repository, asset, file, or page does not state a licence, the default position on this site is that rights are reserved. You may still use any independent right the law gives you, such as a statutory copyright exception where its conditions are met. That is a legal test, not a vibe.

A licence is extra permission, with conditions. It is not a vibe either.

What a licence is for

A software licence answers a practical question: what may I do with this, and what must I do in return?

Typical permissions are use, copy, modify, and distribute. Typical conditions are keeping notices, sharing source, marking changes, or limiting commercial use. Typical disclaimers say there is no warranty.

If you want to do something the licence does not grant, you need a separate permission. Asking after the fact is not a substitute.

Open source is a family of permissions, not one rule

“Open source” is a useful shorthand and a sloppy one. Two files can both be open source and still be incompatible with each other.

Permissive licences, such as MIT or Apache License 2.0, generally allow use, modification, and distribution, including commercially, if you keep the required notices. Apache 2.0 also includes an express patent licence from contributors, subject to its terms, and has extra notice rules including any NOTICE file.

Copyleft licences, such as GNU GPLv3, also let you run, study, modify, and convey the covered software. Conveying a covered work can trigger source-code, notice, and licence obligations. Modified covered files may need to remain under GPLv3 when conveyed. Whether a particular combination is a derivative work or a separate aggregate is fact-specific; the GPL text is the authority, not a blog summary.

Creative Commons licences are more often used for assets, media, or documentation than for code. CC BY-NC-ND, where it is expressly applied, permits sharing with attribution, non-commercial use, and no distribution of adaptations, subject to the exact licence.

None of those summaries replaces the licence. They exist so you know which document to read.

Hosted software is not a downloadable licence

Access to a hosted feature is not a licence to copy the underlying implementation. Private services, APIs, backend code, premium assets, and some downloads may be proprietary even when a public page is visible.

Use those services through authorised interfaces and within account or feature limits. Do not copy, redistribute, or commercially exploit proprietary material without permission. Any restriction on reverse engineering applies only to the extent the law allows and does not remove mandatory statutory rights.

Downloads have their own terms. See the Download Terms.

Third-party material rides along

A project can contain someone else's code, fonts, artwork, names, or APIs. The licence for original mas0ng.com material does not override those third-party terms.

Trade marks, logos, and brand names are not licensed merely because some nearby code is open source. Using a name because the source is public is a good way to pick the wrong fight.

How to read a mas0ng.com project

  1. Look for a LICENSE, COPYING, notice, download page, or other clear statement.
  2. Read that text, not a paraphrase.
  3. Check whether assets, documentation, and code are under the same terms.
  4. If nothing is stated, treat rights as reserved.
