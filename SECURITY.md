# Security policy

This repository contains the public static website served at
[mas0ng.com](https://mas0ng.com). Its scope is the public HTML, CSS,
JavaScript, images, public configuration, and static hosting headers committed
to this repository.

## Report a static-site vulnerability

If the vulnerability is confined to this repository or the public static
website, please use GitHub's private vulnerability reporting flow:

[Privately report a vulnerability](https://github.com/mas0ng/website/security/advisories/new)

Examples include an exploitable issue in a public page, client-side script,
static asset, or static hosting configuration. Please include the affected URL
or file, the impact, clear reproduction steps, and a minimal proof of concept
where useful.

Only the current production site and the latest version of the default branch
are supported.

## Report authentication, API, or Worker vulnerabilities

Do not publish vulnerabilities involving authentication, sessions,
authorisation, protected applications, APIs, Cloudflare Workers, backend
services, or private infrastructure in this repository.

Use the [private security report form](https://mas0ng.com/legal/security.html?reportModalPopup=true)
so the report reaches the service owner without exposing sensitive details.
Do not include active passwords, session tokens, private keys, or unnecessary
personal data.

For a non-security bug or content problem limited to this static website, use
the repository's normal GitHub issue tracker.
